# Technique Maker
---

## 概要

Technique Maker は、MIDIファイルを読み込んでAfter Effectsのレイヤーにキーフレームを自動生成するスクリプトです。
音楽のノーツに合わせて反転・ピンポン再生・拡大縮小・移動などのアニメーションを一括で適用できます。

---

## 動作環境

- After Effects 2025 以降で動作確認
- 対応MIDIフォーマット: SMF Type 0 / Type 1（トラック1を使用)
---

## インストール

1. スクリプトファイル（.jsx）をAfter Effectsの `Scripts` フォルダに配置する
2. After Effectsを起動し、メニューの `ファイル > スクリプト > スクリプトを実行` から選択する
3. または `Scripts/ScriptUI Panels` に配置するとウィンドウとして常駐させることもできる

---

## 使い方

1. アニメーションを適用したいレイヤーを選択した状態でスクリプトを実行する
2. UIウィンドウで Mode・Options・Easing・BPM を設定する
3. 「Run」ボタンを押してMIDIファイルを選択する
4. MIDIのノーツに合わせてキーフレームが自動生成される

> ※レイヤーのイン点・アウト点の範囲内でキーフレームが生成されます。レイヤーをコンポの途中に配置している場合も正しく動作します。

---

## モード一覧

| モード | 対象プロパティ | 説明 |
|--------|---------------|------|
| **Flip** | Scale / Time Remap | ノーツに合わせてX/Y軸を反転。タイムリマップも同期してリトリガーされる。 |
| **Pingpong** | Time Remap | 指定フレーム範囲を順再生→逆再生と交互に繰り返す。 |
| **Scale** | Scale | ノーツに合わせて100%→指定%→100%と拡大縮小を繰り返す。 |
| **Move** | Position | ノーツに合わせて上下または左右に往復移動する。 |

---

## 設定項目

| 設定項目 | 対象モード | 説明 |
|----------|-----------|------|
| Axis (X / Y) | Flip | 反転する軸を選択。X=左右反転、Y=上下反転。 |
| Range (frames) | Pingpong | 1往復分の再生範囲をフレーム数で指定。メディアより長い場合は自動ループ。 |
| Max scale (%) | Scale | 拡大縮小の最大値。100%から指定値まで変化する。 |
| Axis (X / Y / XY) | Scale | スケールをかける軸を選択。XYで縦横均等にスケール。 |
| Direction (H / V) | Move | 移動方向。Horizontal=左右、Vertical=上下。 |
| Range (px) | Move | 移動距離をピクセルで指定。中心から±半分ずつ動く。 |
| Easing | 全モード | None / In / Out / In-Out から選択。Noneはリニア補間。 |
| BPM | 全モード | MIDIのテンポ。楽曲のBPMに合わせて入力。 |

---

## モード別詳細

### Flip

ノーツのOn時刻にScale（X or Y）を±100%でトグルし、タイムリマップをリトリガーします。
- 左右反転テクニック等にご利用ください。

> ※Flipモードはタイムリマップを使用するため、動画またはプリコンプレイヤーに適用してください。

### Pingpong

指定フレーム範囲を順再生または逆再生します。ノーツごとに再生方向が交互に切り替わります。
- ドアテクなどにご利用ください。

> ※RangeはMIDIのノート長に関係なく固定されます。速いノートほど高速再生になります。

### Scale

ノーツのOn〜Off区間でスケール値が変化します。ノーツごとに拡大→縮小が交互に切り替わります。
- 厳禁とかで使えるかもしれません。

> ※Scaleモードはタイムリマップを使用しません。静止画レイヤーにも適用できます。

### Move

ノーツのOn〜Off区間でPositionが移動します。ノーツごとに往復方向が交互に切り替わります。

- 厳禁とかで使えるかもしれません。
- 中心位置から ±Range/2 の範囲で往復します。

> ※Moveモードはタイムリマップを使用しません。全てのレイヤータイプに適用できます。

---

## イージング

補間タイプをモードごとに設定できます。

- **None**: リニア補間
- **In**: 開始をゆっくり、終わりを速く
- **Out**: 開始を速く、終わりをゆっくり
- **In/Out**: 開始と終わりをゆっくり、中間を速く

> ※FlipモードのタイムリマップはイージングなしのLINEAR固定です。ScaleのHOLDキーにもイージングは適用されません。

---

## 既知のバグ
- Pingpongモードにおいて、midiの長さがメディアの長さよりも大きい場合にメディアの最終地点からのキーフレームが打たれない
- Pingpongモードにおいて、EasingがNoneの場合でもイージングがかかってしまう。

---

## 注意事項

- スクリプト実行前に必ず対象レイヤーを選択してください
- Flip / Pingpongモードはタイムリマップを使用するため、静止画・テキスト・シェイプレイヤーには使用できません
- MIDIのテンポがDAW上と異なる場合はBPMを正確に入力してください
- スクリプト実行はUndoグループでまとめられているため、`Ctrl+Z`（`Cmd+Z`）で一括取り消しできます
- 同一レイヤーに複数回実行すると既存のキーフレームに追加されます。再実行前にキーフレームを削除することを推奨します
